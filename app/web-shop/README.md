# Crate Digging — 레코드 가게 앱 (디자인 시안)

기존 웹앱(`../web`)은 그대로 두고, 같은 API(:8000)를 쓰는 새 화면. 마음에 들면 `web`과 바꾸면 된다.

```
cd app/web-shop && npm run dev   # http://localhost:5174
```

- 앱 셸: 사이드바(가게 안내판·지난 크레이트·어젯밤 디깅·취향 유형) | 오늘의 크레이트 | 점원(⌘K) · 아래 재생 바
- 랙: 판을 끌기·휠·←→로 넘기고, 가운데 판을 누르거나 Space로 재생하면 판이 슬리브에서 나와 돈다
- 배경: 고른 판의 앨범아트를 크게 흐려 천천히 돌린다 (albumColor.ts가 강조색도 바꾼다)
- 턴테이블: 재생 바의 앨범아트를 누르면 펼쳐진다. 가사 자리에 이 곡을 고른 원문이 흐른다
- `api.ts`, `albumColor.ts`는 `../web/src`에서 복사, `player.tsx`는 복사 후 seek만 추가
- 아직 없음: 취향 지도(기존 화면 링크), 취향 노트 편집
